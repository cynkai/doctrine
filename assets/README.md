## 촬영 팁

- 배경 배지에 `OPENAI · gpt-4o`가 보이게 찍으면 "실제 LLM"이 한눈에 증명됩니다.
- 정직성 어필용으로 `OPENAI · gpt-4o`(LLM)와 `LOCAL · 규칙 기반`(폴백) 두 버전을 나란히 두면 강합니다.
- macOS: `Cmd+Shift+4` → 스페이스바 → 창 클릭 = 창 단위 깔끔한 스크린샷.
